Data and Methodology
EA area: calculated from polygon geometry using Turf.js.

Cropland: taken from uploaded EA statistics. WorldCover is a contextual land-cover layer and is not automatically converted to polygon statistics here.

NDVI / EVI / SAVI: require processed satellite raster values or an uploaded EA statistics table. Satellite imagery display alone does not calculate these indices.

Climate: Open-Meteo forecast API at the selected EA centroid. Forecast is not a measured station record.

Terrain: a DEM-based EA elevation and slope analysis must be calculated from a DEM raster. No terrain statistics are invented.

Yield and crop area: require agricultural survey, crop-cut or validated remote-sensing statistics.
